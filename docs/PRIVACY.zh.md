# 隐私与安全说明

澜页 / MarginMind 当前是本地 MVP。它涉及摄像头、阅读文档、视线轨迹和 AI API，因此默认设计原则是：能留在本地的就留在本地，能不采集的就不采集。

## 当前不会做什么

- 不采集声音。
- 不上传摄像头画面。
- 不把原始摄像头帧保存到项目目录。
- 不把 `.env`、API key、`storage/` 或日志作为开源仓库内容。

## 本地会保存什么

运行时会在 `storage/` 下保存：

- 上传的文档。
- 文档解析结果。
- 阅读会话事件。
- gaze 样本坐标和时间戳。
- 页面文字框布局。
- AI 内部上下文 `ai_context.json`。
- AI 提示词 `ai_prompt.md`。
- 最终笔记 `notes.md`。

这些文件可能包含个人阅读材料和学习行为信息，不应提交到 GitHub。

## 会发送给 AI 什么

点击生成笔记时，系统会提交：

- 本次会话实际阅读过的页。
- 这些页的原文上下文。
- 每页视线关注摘要。
- 用户主动选中的文本。
- 用户填写的笔记需求。

系统不会提交摄像头画面和声音。原文上下文只用于让模型理解内容，笔记主干应优先依据视线重点和主动标注。

## 摄像头指示灯

很多电脑摄像头旁边的灯是硬件或系统级隐私指示灯。通用 Web/Python 程序通常不能在继续使用摄像头的同时单独关闭该灯。MVP 的正确做法是：需要关灯时停止视线追踪并释放摄像头。

## 发布前检查清单

发布到 GitHub 前请确认：

- `.env` 没有被提交。
- `storage/` 没有被提交。
- `server*.log` 没有被提交。
- 真实 API key 没有出现在 README、issue、commit、截图中。
- 个人阅读文档没有被提交。
- 原始个人想法草稿没有被提交，公开文档使用整理后的描述。

如果 API key 曾经出现在公开位置，应立即在服务商平台作废并重新生成。
